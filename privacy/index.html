Privacy Policy

BubbleComet Pin Poster. Effective 18 October 2026.

BubbleComet is an independent artist's shop on Redbubble. BubbleComet Pin Poster is a small private tool the shop owner runs on their own computer to post pictures of the shop's own designs to the shop's own Pinterest account. It has no other users and no public sign-up.

What the tool accesses

When the shop owner connects the tool to Pinterest, Pinterest lets it:

  • read the connected account's basic profile (username and account type),
  • read and create boards on that account, and
  • read and create pins on that account.

The tool only acts on the shop's own Pinterest account. It does not read, collect or store information about other Pinterest users, their pins, boards, followers or messages.

What is stored, and where

The access token Pinterest issues, and the date it expires, are kept in a settings file on the shop owner's computer. Nothing is sent to any server other than Pinterest's. The tool keeps a list of the pins it has published (title, board, link and pin address) so it does not post the same pin twice.

What is shared

Nothing is sold, shared or used for advertising. Pin images, titles, descriptions and links are sent to Pinterest only to publish the pin, and each pin links to the matching design on Redbubble.

Cookies and tracking

Neither the tool nor this page uses cookies, analytics or tracking. This page is hosted on GitHub Pages, which may keep standard server logs; see GitHub's privacy statement.

Removing access

The connection can be ended at any time from Pinterest's settings, under apps with access to the account. Doing so cancels the stored token; the shop owner then deletes it from the settings file.

Changes

If this policy changes, the new version is posted on this page with a new effective date.

Contact

Questions about this policy: open an issue at github.com/sweetmage/bubblecomet/issues, or message BubbleComet on Redbubble.
